# Phase 1: Authentication & Authorization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SSKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace in-memory client-side auth with server-side sessions using SvelteKit sessions.

**Architecture:** 
- Use SvelteKit sessions (`@sveltejs/kit/session`) with a session store
- Store session IDs in cookies with secure flags
- Move auth logic to server-side middleware
- Add CSRF protection using double-submit cookie pattern
- Add logout endpoint that invalidates session

**Tech Stack:** 
- `@sveltejs/kit/session`
- `@sveltejs/kit/hooks.server.ts`
- `@sveltejs/kit/adapter-node`
- `cookie` (for secure cookie flags)

**Spec:** See `docs/superpowers/plans/2026-10-28-saas-readiness-audit.md` findings #1, #2, #11, #12, #13

## Global Constraints

- **Svelte 5 Runes:** All components must use `$props()`, `$state`, `$derived`, `$effect`
- **TypeScript Strict:** No `any` without explicit comment
- **Indonesian Domain Identifiers:** Technical terms stay English (`login`, `logout`, `session`)
- **UI Copy:** English only
- **File Structure:** `src/lib/stores/auth.ts` is client-only; move session logic to `hooks.server.ts`
- **Testing:** Tests must be colocated with the code they test

## Review Focus

1. **Auth bypass:** A user can access `/member` without being logged in → Test: Call `/member` with no cookies; should redirect to `/login`
2. **Session persistence:** Refreshing the page keeps the user logged in → Test: Login, refresh page, verify still logged in
3. **Logout:** Logging out invalidates the session → Test: Login, logout, refresh page, verify redirected to `/login`
4. **CSRF attack:** A malicious site cannot submit forms → Test: Submit a form from a different origin
5. **Cookie security:** Session cookies use secure and httpOnly flags → Test: Check cookie attributes in browser dev tools

- [ ] **Step 1: Create `src/lib/server/sessionStore.ts`**

```typescript
import type { Session, SessionData, SessionStorage } from '@sveltejs/kit/session';

export const cookieConfig = {
	name: 'tokoku_session',
	maxAge: 60 * 60 * 24 * 7, // 7 days
	httpOnly: true,
	path: '/',
	sameSite: 'lax',
	secure: true // Set to false in development
} as const;

export const sessionStore = async ({
	request,
	cookies
}: {
	request: Request;
	cookies: {
		get: (name: string) => string | undefined;
		set: (name: string, value: string, options: { path?: string; maxAge?: number; httpOnly?: boolean; sameSite?: string; secure?: boolean }) => void;
		delete: (name: string, options?: { path?: string; httpOnly?: boolean; sameSite?: string; secure?: boolean }) => void;
	};
}): Promise<SessionStorage<SessionData>> => {
	const getSession = async () => {
		const sessionCookie = cookies.get(cookieConfig.name);
		if (!sessionCookie) return null;
		return { userId: sessionCookie };
	};

	const setSession = async (userId: string) => {
		cookies.set(cookieConfig.name, userId, cookieConfig);
	};

	const deleteSession = async () => {
		cookies.delete(cookieConfig.name, cookieConfig);
	};

	return {
		getSession,
		setSession,
		deleteSession
	};
};
```

```typescript
export const POST = async ({ request, cookies }) => {
	const body = await request.json();
	const { email, password } = body;

	if (!email || !password) {
		return new Response(JSON.stringify({ errors: { email: 'Email is required', password: 'Password is required' } }), {
			status: 400,
			headers: { 'content-type': 'application/json' }
		});
	}

	const POLA_EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
	if (!POLA_EMAIL.test(email.trim()) || password.trim() === '') {
		return new Response(JSON.stringify({ errors: { email: 'Enter a valid email', password: 'Password is required' } }), {
			status: 400,
			headers: { 'content-type': 'application/json' }
		});
	}

	// TODO: Replace with real authentication (database check)
	const validEmail = 'rina@tokoku.id';
	const validPassword = 'rahasia';

	if (email === validEmail && password === validPassword) {
		const { setSession } = await sessionStore({ request, cookies });
		await setSession(`user-${Date.now()}`);

		return new Response(null, {
			status: 303,
			headers: { location: '/' }
		});
	}

	return new Response(JSON.stringify({ errors: { email: 'Invalid email or password' } }), {
		status: 401,
		headers: { 'content-type': 'application/json' }
	});
};
```

- [ ] **Step 1: Create CSRF utilities**

```typescript
import { randomBytes } from 'crypto';

export function generateCsrfToken(): string {
	return randomBytes(32).toString('hex');
}

export function validateCsrfToken(token: string, expected: string): boolean {
	return token === expected;
}

export function csrfHeader(token: string): string {
	return `X-CSRF-Token: ${token}`;
}
```

- [ ] **Step 2: Add CSRF to session store**

Modify `src/lib/server/sessionStore.ts` to store CSRF token in session:

```typescript
export const sessionStore = async ({
	request,
	cookies
}: {
	request: Request;
	cookies: {
		get: (name: string) => string | undefined;
		set: (name: string, value: string, options: { path?: string; maxAge?: number; httpOnly?: boolean; sameSite?: string; secure?: boolean }) => void;
		delete: (name: string, options?: { path?: string; httpOnly?: boolean; sameSite?: string; secure?: boolean }) => void;
	};
}): Promise<SessionStorage<SessionData>> => {
	const getSession = async () => {
		const sessionCookie = cookies.get(cookieConfig.name);
		if (!sessionCookie) return null;
		return { userId: sessionCookie };
	};

	const setSession = async (userId: string) => {
		const csrfToken = generateCsrfToken();
		cookies.set(cookieConfig.name, userId, cookieConfig);
		cookies.set('csrf_token', csrfToken, { ...cookieConfig, maxAge: 60 * 60 * 24 });
	};

	const deleteSession = async () => {
		cookies.delete(cookieConfig.name, cookieConfig);
		cookies.delete('csrf_token', { ...cookieConfig, maxAge: 0 });
	};

	return {
		getSession,
		setSession,
		deleteSession
	};
};
```

- [ ] **Step 3: Add CSRF middleware to API routes**

Create `src/routes/api/csrf/+server.ts`:

```typescript
import { json } from '@sveltejs/kit';
import type { RequestHandler } from './$types';
import { sessionStore } from '#lib/server/sessionStore';

export const GET: RequestHandler = async ({ request, cookies }) => {
	const { getSession } = await sessionStore({ request, cookies });
	const session = await getSession();

	if (!session?.userId) {
		return json({ error: 'Unauthorized' }, { status: 401 });
	}

	const csrfToken = cookies.get('csrf_token');
	return json({ csrfToken });
};
```
